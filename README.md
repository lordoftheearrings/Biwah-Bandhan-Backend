# 🔗 Biwah Bandhan – Matrimonial App (Backend)

**Biwah Bandhan** is a Django-based backend powering a modern matrimonial application. This backend manages user authentication, profile data, matchmaking logic, and kundali analysis using a structured and scalable REST API.

## 🚀 Overview

Biwah Bandhan's backend is responsible for handling all server-side operations for the mobile app, including:

- 🧾 User registration and authentication 
- 📄 Profile creation, update, and filtering
- 🧠 Matchmaking using a weighted compatibility algorithm
- 🕉️ Kundali generation and compatibility matching using astrology data
- 🔁 API integration for frontend communication
- 💬 Chat handling 
- 📂 SVG-based Kundali file generation and delivery

This backend is designed to be modular and easily integrable with any frontend using RESTful APIs.

## 🛠️ Technologies Used

- Python 3.x
- Django
- Django REST Framework (DRF)
- PostgreSQL
- django-cors-headers
- django-channels (for WebSocket chat, WIP)
- Astrological calculations & SVG generation (custom logic)
